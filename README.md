# ASBRegRef

Asbestos Threshold & Disposal Decision Guide — Kustom Ventura Division field
reference (SCAQMD / AVAQMD / VCAPCD). The guide is a single self-contained
page, `index.html`, served via GitHub Pages.

## Live site

https://damiex-rvnx.github.io/ASBRegRef/

## Enabling GitHub Pages (one-time)

Pages can only be turned on from the repository settings — it can't be enabled
programmatically. To publish:

1. Go to **Settings → Pages**.
2. Under **Build and deployment → Source**, choose **Deploy from a branch**.
3. Set **Branch** to `claude/github-pages-file-visibility-tahzkt` and the folder
   to **`/ (root)`**, then **Save**.

The site builds in a minute or two and appears at the URL above. `.nojekyll`
tells Pages to serve the files as-is without Jekyll processing.
